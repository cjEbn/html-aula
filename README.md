# PetCão — página de pet shop

Exercício acadêmico de desenvolvimento web realizado durante uma aula de HTML. O projeto apresenta uma página conceitual de pet shop com seções de apresentação, galeria, mapa e contato.

## Objetivo

Praticar a estruturação de uma página com HTML e a aplicação de estilos com CSS, organizando conteúdo em seções e incluindo elementos comuns de uma página institucional. É um exercício de aprendizagem, não um serviço real.

## Tecnologias

- HTML5
- CSS3

## Estrutura relevante

- `aula01/index.html` — página HTML do exercício.
- `css/style.css` — folha de estilos versionada na raiz do repositório.
- `Img` — item de recursos existente no repositório; confira sua estrutura e os caminhos referenciados no HTML antes de executar a página.

## Como visualizar

1. Clone ou baixe este repositório.
2. Abra `aula01/index.html` em um navegador.
3. Observe que os caminhos relativos de CSS e imagens e o endereço do mapa incorporado precisam ser conferidos/ajustados para a estrutura atual dos arquivos. Não há demonstração hospedada documentada.
